# Mercury documentation

- [BUILDING.md](BUILDING.md) describes source preparation, platform builds,
  native and portable packaging, cross-compilation, and localized release
  entry points.
- [RELEASING.md](RELEASING.md) defines the PGO and localization model, complete
  platform/CPU artifact matrix, historical release mapping, and publication
  checklist.
- [SYSTEM_REQUIREMENTS.md](SYSTEM_REQUIREMENTS.md) lists the supported target
  platforms and CPU requirements for release variants.
- [GIT_SETUP.md](GIT_SETUP.md) documents Firefox Git checkout management,
  release pins, revision changes, and Mercury source preparation.
- [PATCHES.md](PATCHES.md) documents the selected Firefox release, the
  machine-readable patch manifest and roles, retained source overlays, and
  release assembly inputs.
- [LOCALIZATION.md](LOCALIZATION.md) documents the all-Firefox-locale audit,
  reviewed/machine-draft policy, and reproducible localized-package and
  language-pack release workflows.
- [PREFERENCES.md](PREFERENCES.md) records the current Firefox preference audit,
  ownership, effectiveness constraints, and migration decisions.
- [DEBUGGING.md](DEBUGGING.md) lists current runtime debugging options and
  resources.
